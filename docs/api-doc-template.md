# API 文档编写模板

每个接口一个 Markdown 文件，放在对应服务目录下。

## 模板

```markdown
# 服务：<服务名，如 MES>

## 接口：<接口名，如 分页查询生产工单>

- **路径：** <HTTP方法> <路径，如 POST /api/mes/producing-work-orders/page>
- **所属模块：** <模块名，如 生产工单>
- **HTTP 方法：** <GET / POST / PUT / DELETE>

**功能说明：**
<用自然语言描述这个接口做什么、什么场景下使用，1-3句话>

**请求参数：**
- <参数名>: <参数说明>
  - <嵌套字段>: <字段说明>（可选）
- ...

**返回字段：**
- <字段名>: <字段说明>
- <嵌套字段>: <字段说明>（可选）
- ...

**适用问题示例：**
- "<用户可能怎么问？>"
- "<另一种问法>"
- "<覆盖更多场景>"
```

## 示例

```markdown
# 服务：MES

## 接口：分页查询生产工单

- **路径：** POST /api/mes/producing-work-orders/page
- **所属模块：** 生产工单
- **HTTP 方法：** POST

**功能说明：**
按条件分页查询生产工单列表，支持按工单号、状态、计划日期等筛选，常用于生产看板和工单管理界面。

**请求参数：**
- query: 查询条件对象
  - orderNo: 工单号（可选）
  - status: 工单状态（可选，草稿/已下达/生产中/已完成）
  - startDate: 计划开始日期（可选）
  - endDate: 计划结束日期（可选）
  - pageNo: 页码
  - pageSize: 每页条数

**返回字段：**
- id: 工单ID
- orderNo: 工单号
- productName: 产品名称
- status: 工单状态
- plannedQty: 计划数量
- completedQty: 已完成数量
- startDate: 计划开始日期

**适用问题示例：**
- "有哪些工单还没完成？"
- "最近一周创建了哪些工单？"
- "某个产品的工单进度怎么样？"
- "查一下生产工单的状态"
- "还有多少工单在生产中？"
```
